# straight-shooters
## 💪 Mass Tracker (`masse/`)

Application web mobile de suivi de prise de masse : analyse des repas par photo (IA Claude), dashboard calories/macros/poids, journal d'entraînement, suivi du poids et photos hebdo, compléments alimentaires. Ouvrir `masse/index.html` (ex. via GitHub Pages : `/masse/`). Données stockées localement dans le navigateur ; la clé API Anthropic se renseigne dans les réglages ⚙️.
